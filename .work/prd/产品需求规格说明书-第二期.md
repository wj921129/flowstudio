# FlowStudio 第二期新功能需求规划与优先级规范 (PRD)

> 文档版本：v1.1.0 ｜ 状态：prd1 & prd2 联合审阅定稿 ｜ 编制：prd1 协同 prd2 ｜ 适用项目：FlowStudio

---

## 1. 背景与现状回顾

### 1.1 第一期现状总结
FlowStudio 第一期已全面达成预期目标，底层 CRDT 协同、elkjs 泳道感知排版、Fastify 服务端架构、7 大 MCP 协作者工具、无损差量快照以及 Linear 现代极简风格工作台等 **6 大核心模块共 24 项细分功能** 均已 100% 交付闭环，全工程 196 项单元/集成/E2E 测试持续全绿。

### 1.2 第二期演进诉求
第一期成功奠定了“**局域网多人实时协作 + 人机共治**”的坚实底座，但在实际业务与团队协同场景中，经过深度排查梳理出 5 项核心深化诉求：
1. **AI 触达门槛**：当前 MCP 工具主要服务于 IDE/Agent 开发者，非技术人员在 Web 界面缺乏直观的 AI 对话与生成入口。
2. **走线与排版极限**：第一期直角连线在手动移动或密集节点拓扑下缺少真实几何避障，易发生穿透节点、连线粘连与折角凌乱。
3. **图表场景局限**：现有体系偏向通用流程与泳道图，缺少架构图、UML 时序图、系统拓扑及业务富文本卡片等高阶图元。
4. **评审与异步协作**：多人协作评审缺乏图钉式批注、评论与解决闭环，团队讨论缺乏画布上下文锚定。
5. **生态与资产互通**：除 Mermaid 外，对主流绘图软件（Draw.io、BPMN 2.0）及剪贴板导入能力亟待补充。

---

## 2. 需求优先级定义标准

按照 MoSCoW 与人机共治价值/技术成本矩阵，将需求划分为三级优先级：
- **P0（核心必做 / Must Have）**：解决核心体验痛点，决定产品下一代核心竞争力的关键功能，优先安排研发。
- **P1（重要推荐 / Should Have）**：显著提升团队工作效率与适用场景覆盖面的关键特性。
- **P2（锦上添花 / Nice to Have）**：增强安全合规、审计回溯与高端演示体验的高级特性。

## 3. 详细功能需求清单

### 3.1 【P0】画布内置 AI Copilot 对话交互面板 (Web 侧人机共治)
- **需求概述**：在 Web 画布右侧提供内置 AI 对话工作台（支持快捷键 `Cmd/Ctrl + J` 唤起与折叠），允许普通用户通过自然语言直接下达图表构建与增量修改指令。
- **核心功能点**：
  1. **自然语言绘图与编辑**：用户输入“在订单支付节点后增加风控校验，若未通过则驳回至用户，放到风控泳道”，AI 解析并自动生成结构化操作。
  2. **复用底层人机共治内核**：对话面板底层与 Fastify MCP 共用相同的增量写入接口（`scaffold_diagram` / `apply_ops`）与 elkjs 排版引擎，严禁全图整量覆盖。
  3. **Visual Diff 交互审阅一体化**：AI 生成的改动直接在画布上以红/绿/黄三色高亮，用户可在对话框或画布审阅台逐项核验，支持“一键采纳”或“驳回”。
  4. **选区感知 Prompt**：支持引用当前画布选中的节点进行局部上下文提问（“帮我细化选中这三个节点的异常补偿逻辑”）。
  5. **意图预览与确认 (Dry-Run Plan)**：AI 执行增量变更前，在对话框提供自然语言操作摘要清单（如“将新增 2 节点，重连 1 条线”），降低用户决策门槛。
  6. **协同 Awareness 广播**：当任一成员调用 AI Copilot 对画布局部进行构思和修改时，通过 Yjs Awareness 广播“AI 正在规划”微型气泡提示，避免多成员冲突。
  7. **快捷指令与模板预设 (Slash Commands)**：内置 `/refine`（文本与排版润色）、`/branch`（补充异常分支）、`/testcase`（生成对应流程测试用例清单）。
- **用户价值**：将 MCP 强大的 AI 增量绘图能力从 IDE 拓展到全体浏览器用户，实现真正全民可用的“人机共治”。

### 3.2 【P0】复杂拓扑智能几何避障连线 (Obstacle Avoidance Routing)
- **需求概述**：解决复杂拓扑下正交连线穿透无关节点与多线粘连问题，实现真正的智能动态避障路由。
- **核心功能点**：
  1. **网格 A* / 几何可见性避障路由**：连线计算时自动把画布上的非关联节点包围盒视为不可穿越障碍物，动态计算最短曼哈顿避障路径。
  2. **连线微型立体跨线桥 (Bridge Jump)**：当两条正交连线不可避免发生正交交叉时，纵向连线自动绘制微型弧形拱桥跳线，清晰表达信号非连接关系。
  3. **动态磁吸锚点停靠优化**：根据连线入射角与邻近节点位置，自动选择最优端点 Handle 停靠，杜绝生硬回折。
  4. **跨泳道走廊感知 (Lane Corridor Awareness)**：连线跨越泳道时优先走公共走廊区域，避免无序斜切无关泳道内部。
  5. **连线分支标签 (Edge Label) 智能防遮挡**：判定分支标签（如“通过/拒绝”）自动沿线居中并避开拐角与节点边框。
  6. **性能平滑节流**：拖拽移动时采用局部脏区域重路由与 RAF 防抖，确保 200+ 节点拓扑下拖动 60fps 不掉帧。
- **用户价值**：彻底消除第一期“直角连线穿透节点”的妥协缺陷，达到专业级商业绘图引擎排版水准。

### 3.3 【P1】图表类型与节点资产库扩展 (UML / 架构图 / 富文本卡片)
- **需求概述**：基于既有扩展节点注册表，横向扩展专业领域图元体系，满足研发、测试与架构设计诉求。
- **核心功能点**：
  1. **UML 与时序图支持**：提供 Lifeline 生命线、Activation Box 激活块、同步/异步消息箭头、类图分段属性卡片。
  2. **系统架构与云原生拓扑组件**：内置微服务、网关、数据库分片、缓存集群、K8s Pod、Docker 等常见架构矢量图元。
  3. **架构元数据与状态徽章 (Status Badges)**：支持在架构节点上贴附环境标签（Prod/Staging）、调用协议（HTTP/gRPC/Kafka）及健康度指示点。
  4. **富文本卡片节点**：支持嵌入 Markdown 内容、富文本列表、负责人头像气泡、状态标签（Draft / WIP / Done）。
  5. **左侧侧边栏分组分类**：左侧图形面板增加“流程 / 泳道 / 架构 / UML / 形状”分类 Tab 与快速拖拽放入体验。
- **用户价值**：从单一流程图平台升级为企业级研发与架构设计综合可视化工作台。

### 3.4 【P1】画布协同批注与评论图钉系统 (Comment & Pinning)
- **需求概述**：支持团队成员在画布任意位置打当下图钉进行点对点异步评审与批注，提升协同沟通效率。
- **核心功能点**：
  1. **图钉打点（Comment Pin）**：支持将评论吸附于指定节点、连线或画布绝对坐标。
  2. **图元脱挂防丢失策略**：若评论吸附的图元被人工或 AI 删除，图钉自动原地脱挂降级为绝对坐标锚点，并显示“关联图元已移除”，确保评审记录 100% 留存。
  3. **Thread 讨论串**：支持多轮文字回复、@在线协作成员、标记表情 Reaction。
  4. **已解决（Resolved）状态流转**：评论支持标记已解决并沉底收起，支持一键切换“仅显示未解决评论”。
  5. **评审模式快速跳转**：提供快捷键与评审抽屉，支持按时间/状态在评论图钉间顺序平滑聚焦（类似 Figma Review Mode）。
  6. **CRDT 实时广播**：评论数据通过 Yjs 数据结构同步，他人新增评论即时弹出微型气泡提醒，点击自动聚焦平移画布。
- **用户价值**：将流程设计与评审闭环原生整合在同一画布内，替代低效的聊天工具截屏圈画。

### 3.5 【P1】多格式数据导入与跨生态互通 (Draw.io / BPMN 2.0)
- **需求概述**：打通与主流绘图工具的数据资产管道，降低企业既有图表资产迁移门槛。
- **核心功能点**：
  1. **Draw.io (.drawio / XML) 导入**：解析标准 Draw.io 压缩/未压缩 XML 结构，将其图形、样式与坐标无损转换为 FlowStudio 节点与连线。
  2. **BPMN 2.0 规范导入与导出**：支持国际业务流程管理标准 BPMN 2.0 XML 互通，便于合规审计与企业审批流落地。
  3. **剪贴板智能识别与粘贴**：支持从剪贴板直接粘贴 Mermaid 代码字符串或 SVG 矢量图，自动触发识别并转为画布图元。
  4. **单文件交互式 HTML 离线导出**：一键导出包含内嵌轻量渲染脚本的单 HTML 文件，离线双击即可带看、缩放与聚光灯聚焦，免配服务。
- **用户价值**：打消企业“被单一工具锁定”的顾虑，大幅降低旧系统历史画图资产迁移成本。

### 3.6 【P2】快照历史版本 Visual Diff 可视化比对
- **需求概述**：将当前仅用于 AI 批次撤回的 Visual Diff 能力扩展到全量时间线快照版本之间。
- **核心功能点**：
  1. **快照版本差异对比**：在时间线抽屉中选择任意两份历史快照（或历史快照与当前画布），触发可视化差异比对。
  2. **红绿黄差异高亮标注**：绿色标明相对新增图元、黄色标明属性/坐标变动图元、红色虚线标明相对删除图元。
  3. **差异清单侧边栏**：提供变更项目列表，点击任意变动项自动聚焦平移至该图元位置。
- **用户价值**：赋予用户像 Git Diff 一样直观清晰的架构与流程版本回溯审查体验。

### 3.7 【P2】只读安全分享、全屏演讲模式与安全水印
- **需求概述**：提供安全的只读分享模式与面向会议汇报的演示演讲能力。
- **核心功能点**：
  1. **只读访问链接**：生成带只读标记的 URL，访问端禁用所有写操作，仅保留查看、高亮跟随与导出权限。
  2. **全屏演讲演示模式**：提供全屏无边框展示视图，支持预设“故事板/幻灯片”节点序列，按空格键顺滑推进镜头带看。
  3. **动态安全防泄密水印**：画布可选叠加半透明网格水印，动态渲染访客 IP、用户名、访问时间戳，防止敏感架构泄密。
- **用户价值**：满足重大方案评审、领导汇报与企业安全风控合规要求。

## 5. 验收标准与质量把控 (DoD)

1. **AI Copilot**：
   - 交互响应时延 ≤ 1.5s（首 Token 流式返回）；
   - 所有 AI 变更 100% 走增量事务，自动挂载 Visual Diff，人工修改图元跳过保护率 100%；
   - 支持 Dry-Run 预执行摘要展示与撤销回退。
2. **避障连线**：
   - 包含 50+ 节点复杂图场景下，连线与无关节点包围盒的碰撞重叠发生率降低 90% 以上；
   - 交叉连线微型拱桥绘制准确率 100%；
   - 拖拽平滑度保持 ≥ 55fps。
3. **协同批注**：
   - 局域网 5 人同时发评论与回复，数据 0 丢失，实时更新延迟 ≤ 100ms；
   - 关联节点删除后图钉平滑脱挂降级，评论数据留存率 100%。
4. **导入导出**：
   - 常见 Draw.io 流程图导入图形还原度 ≥ 95%，自动布局对齐正常；
   - 剪贴板快速粘贴 Mermaid/SVG 成功识别率 ≥ 90%。
5. **代码与测试**：
   - 所有新增功能必须配套 Vitest 单元与集成测试，全量测试套件保持 100% 通过；
   - 遵循人机共治工程红线，严禁全图整量覆盖。
