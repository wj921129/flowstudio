## 二、第二期 7 大核心功能模块交付全景清单

### 1. 【P0】画布内置 AI Copilot 对话交互面板 (Web 侧人机共治)
- **快捷唤起与常驻入口**：支持全局快捷键 `Cmd/Ctrl + J` 唤起/折叠对话面板，TopBar 配备智能呼吸入口；
- **增量协同事务**：复用 Fastify MCP 增量协议（`scaffold_diagram` / `apply_ops`），执行变更严格限制在增量差量，杜绝全图重写；
- **Dry-Run 意图预演与差异高亮**：改动前输出差异预演，执行后自动挂载 Visual Diff 三色高亮，支持一键采纳与安全撤回；
- **选区感知与快捷指令**：实时关联选中节点上下文，支持 `/refine`、`/branch`、`/testcase` 等结构化 prompt；
- **Awareness 协同广播**：光标在画布内/外均广播协同状态，TopBar 联动脉冲徽标提示，避免多人冲突。

### 2. 【P0】复杂拓扑智能几何避障连线与立体跨线桥 (Obstacle Avoidance Routing)
- **网格 A\* 避障寻路**：实时计算动态障碍物网格，无碰撞绕行无关节点包围盒；
- **立体跨线拱桥 (Bridge Jump)**：交叉连线纵向自动绘制微型跳线弧形拱桥（`A 5 5 0 0 0`），解耦视觉交叉；
- **动态磁吸与避让标签**：按相对包围盒智能选取进出 Handle 端点，分支标签避开障碍物与连线拐角；
- **RAF 节流与性能保障**：单帧路由缓存加权调度，在 50+ 节点密集复杂图下拖拽保持 60fps 流畅。

### 3. 【P1】画布协同批注与评论图钉系统 (Comment & Pinning)
- **图钉吸附与脱挂防丢**：支持在画布任意位置、节点或连线上精准打点（快捷键 <kbd>C</kbd>）；吸附图元被删时原地脱挂降级为绝对坐标并标明脱挂原因，评论留存率 100%；
- **Thread 讨论串与 Reaction**：支持多轮文字回复、@协作成员与 5 种快捷表情互动；
- **解决流转与带看模式**：支持已解决/未解决沉底流转；评审抽屉（Review Mode）支持键盘左右方向键平滑镜头聚焦带看；
- **CRDT 实时广播**：评论数据通过 Yjs 数据结构同步，他人新增评论即时弹出微型气泡提醒，点击自动聚焦平移画布。

### 4. 【P1】图表类型与节点资产库扩展 (UML / 架构图 / 富文本卡片)
- **UML 时序图元**：生命线 (uml-lifeline)、激活块 (uml-activation)、时序消息箭头 (uml-message，支持 sync/async/return)；
- **6 种云原生架构图元**：微服务、API网关、分片DB、分布式缓存、K8s Pod、Docker 容器，支持环境徽章、协议徽章与健康指示灯；
- **富文本卡片**：rich-card 支持 Markdown 即时编辑渲染、负责人头像与任务状态徽章；
- **资产面板重构**：侧边栏整合为 5 大 Tab（流程/泳道/架构/UML/形状）并支持跨分组实时聚合检索；
- **MCP 联动升级**：服务端 `scaffold_diagram` 遵循图元注册表默认尺寸，实现人机两侧语义一致。

### 5. 【P2】只读安全分享、全屏演讲演示与动态防泄密水印
- **只读安全受控模式**：`?readonly=true` 下在交互层与文件层双重锁定写操作，禁止拖拽、增删图元与连线，隐藏排版/AI/恢复入口，保留漫游查看与走查；
- **全屏故事板演讲模式**：按因果拓扑流智能编排镜头，空格键/方向键顺滑推进，支持 3.5s 自动轮播与聚光灯聚焦降噪；
- **动态防泄密水印**：顶层半透明平铺渲染访客昵称、Client ID、访问时间戳与内部机密标识，穿透事件阻断。

### 6. 【P1】多格式数据导入与跨生态互通 (Draw.io / BPMN 2.0 / 离线HTML / 剪贴板识别)
- **多格式导入导出**：TopBar 智能识别 `.drawio` / `.bpmn` / `.xml` / `.json` 并精准对齐几何与泳道坐标；支持导出标准 BPMN 2.0 XML 与轻量离线交互单文件 HTML；
- **剪贴板智能识别**：画布直接 <kbd>Ctrl</kbd>+<kbd>V</kbd> 解析 Mermaid、Draw.io XML 与 BPMN 文本并转换追加；
- **防冲突与安全拦截**：冲突 ID 自动重映射保证渲染一致性，只读模式下阻断文件接收通道。

### 7. 【P2】快照历史版本 Visual Diff 可视化比对
- **全版本任意比对**：时间线抽屉内支持任意选择两个快照版本（或历史快照与当前画布）进行差异比对；
- **红绿黄三色高亮标注**：绿色标明相对新增图元、黄色标明属性/坐标变动图元、红色虚线标明相对删除图元；
- **差异清单侧边栏聚焦**：左侧展示变更清单，点击任意图元条目自动平滑平移至该图元几何中心。
