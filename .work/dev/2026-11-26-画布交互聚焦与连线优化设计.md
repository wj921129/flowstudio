# 画布交互聚焦与连线优化设计

## 1. 目标与非目标

- **目标**：
  1. **鼠标移入聚焦**：移入非容器节点时，当前节点与直接相连（1 跳）的相邻节点色彩加深，直连连线加粗；其余无关节点与连线透明度降至 `0.8`（含聚焦子节点的父级泳道/泳池/分组保持 `opacity: 1`）。
  2. **连线重叠加粗**：多条连线共线重合的区段按重叠数量阶梯加粗，仅加粗重合子区间，颜色优先采用选中/聚焦边颜色。
  3. **连线任意点调形与防误重联**：关闭 React Flow 默认端点重联热区，仅保留起终点圆环手柄触发重联；选中连线后，任意位置及任意折段（含首尾段与单段直线）均可拖动调整，拐角可双向拖动，全过程维持正交且绝不触发重联。
  4. **选中元素流向圆点**：选中节点且非聚光灯态时，直接相连的连线上每 `0.5s` 从起点向终点匀速（`160px/s`）发射小圆点，替代单选自动虚线蚂蚁线。
- **非目标**：不改变 `Alt+Click` 因果全链路聚光灯走查；不修改 `@flowstudio/shared` 与服务端 MCP 契约；不改变平移/只读模式的交互封锁规则。

## 2. 方案与取舍

采用**复用现有渲染管线 + 原生 SVG 合成**：
- 扩展 `deriveDisplayNodes` 节点级缓存与 CSS `filter` 覆盖所有 21 种图元（含 SVG 异形）。
- 扩展 `EdgeRoutingManager` 登记全方向线段并经扫描线切分重叠子区间，由代表边在原生边 SVG 层绘制加粗重叠路径，避免独立覆盖层导致的层级遮挡与导出失真。
- 在 `OrthogonalEdge` 内使用原生 SVG `<circle>` + `<animateMotion>` 实现零 JS 定时器开销的恒速流向圆点。

## 3. 默认参数与涉及文件

- 重叠检测：共线坐标容差 `1px`、最小重合长度 `1px`、步长 `+1.4px`、上限 `10px`。
- 连线调形：首尾拆折保留短桩 `16px`、线段透明热区宽 `14px`、拖拽启动阈值 `3px`。
- 流向圆点：发射间隔 `0.5s`、恒定速度 `160px/s`、单线同屏上限 `20` 颗。
- 涉及文件：`edge-overlap-utils.ts`（新增）、`edge-routing-manager.ts`、`custom-edges/index.ts`、`waypoint-path-utils.ts`、`orthogonal-edge.tsx`、`display-nodes.ts`、`tokens.css`、`flow-canvas.tsx`，及既有单测扩展。
