## 三、待接力工单清单与执行路线图（Frontier）

后续接力 Agent 应依序推进剩余 7 张工单：

```
已完成 (9/16): [01] [02] [03] [04] [05] [06] [07] [11] [12]
待接力 (7/16):
  ├─ 阶段 2 (人机协同): [08] -> [09] -> [10]
  ├─ 阶段 3 (性能调度): [13]
  └─ 阶段 4 (重构演进): [14] -> [15] -> [16]
```

### 1. 工单 08：`apply_ops` 原子模式与自纠型 MCP 工具契约（阶段 2）
- **目标**：增强 `packages/server/src/mcp/` 下各工具的入参自愈与原子执行能力。
- **要点**：
  - `apply_ops` 增加 `atomic: true` 模式：单个 op 失败整批回滚，并在单事务提交。
  - Zod Schema 明确字段校验边界与中英文友好纠错信息，提供自纠建议提示（如找不到目标节点时返回候选项列表）。
  - `auto_layout` 返回实际位移统计，`warnings` 数组增强。

### 2. 工单 09：AI 批次撤回拓扑完整度校验与细粒度样式退让（阶段 2）
- **目标**：优化 `packages/server/src/collaboration/ai-batch-manager.ts`。
- **要点**：
  - 撤回 AI 节点时，深度校验悬空连线（dangling edges），自动级联回收仅依赖该节点的孤立连线。
  - 支持仅撤回样式/位置变更而保留人工补充的文本或业务字段。

### 3. 工单 10：服务端 AI 实时在线感知广播（阶段 2）
- **目标**：在 `DocumentWriter` 与 `AiCollaborator` 操作期间，通过 Awareness 向前端实时广播 AI 正在编辑的图元与状态。
- **要点**：
  - 在 Yjs Awareness 中注册虚拟用户 `AI Assistant`。
  - 写入前后设置高亮节点 ID 与动作提示，操作完成或超时自动清除。

### 4. 工单 13：正交避障路由空间网格/包围盒索引化与视口外异步调度（阶段 3）
- **目标**：重构 `packages/web/src/lib/edge-routing-manager.ts`。
- **要点**：
  - 将大图避障从 `O(N)` 全量包围盒扫描优化为基于简单网格（Spatial Grid / Bucket）的空间索引。
  - 结合 React Flow `useViewport`，视口外连线降级为快速正交折线，进入视口或拖拽停顿后再异步补全 A* 精细避障。

### 5. 工单 14：节点类型契约单一来源与导出/互操作全量对齐（阶段 4）
- **目标**：消除 `packages/shared/src/types.ts` 与各渲染器间的图元类型漂移。
- **要点**：
  - 以 `FLOW_NODE_TYPES` 常量数组为单一真实来源派生 TypeScript 类型。
  - 补齐所有类型在 Draw.io、Mermaid、BPMN 互操作中的双向映射映射表与测试。

### 6. 工单 15：`node.data` 嵌套协同与迁移基础设施（阶段 4）
- **目标**：支持 `node.data` 深层属性在 CRDT 中的原子修改，建立图表 Schema 迁移版本控制。
- **要点**：
  - 数据库引入 `PRAGMA user_version`，Y.Doc 根元数据引入 `schemaVersion`。
  - 提供无损向上迁移机制。

### 7. 工单 16：巨型模块解耦与工程门禁（阶段 4）
- **目标**：解耦长文件（`ai-collaborator.ts`、`flow-store.ts`），建立统一代码门禁。
- **要点**：
  - `flow-store` 拆分为 `canvas-slice`、`selection-slice`、`history-slice` 等。
  - 配置持续集成脚本与规范检查。
