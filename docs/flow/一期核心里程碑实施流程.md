## 一、第一期建设总览与架构演进

FlowStudio 第一期的建设目标是从零搭建一个**局域网内多人实时协作**的现代流程图与泳道图平台，核心理念是**人机共治**（AI 快速搭建骨架，人工接手修改，AI 增量协同绝不覆盖人改动）。

工程按照渐进式分层架构，划分为 4 大核心里程碑：
- **M1 里程碑（基础画布）**：Monorepo 脚手架、设计系统 Tokens、xyflow 画布、9 种基础图元与单机状态机。
- **M2 里程碑（服务端底座与实时协同）**：Node 22 + Fastify 单进程架构、SQLite 持久化、Hocuspocus (Yjs CRDT) 局域网实时协同与光标感知。
- **M3 里程碑（泳道系统与自动排版）**：Pool/Lane 规范容器体系、elkjs 因果拓扑分层排版引擎、正交折点交互走线。
- **M4 里程碑（AI 协作者 MCP 与快照）**：7 大 MCP 增量操作工具、AI 批次撤回防覆盖账本、无损差量快照回滚、全格式导出与局域网一键启动。

## 二、M1 里程碑：Monorepo 与基础画布构建

### 1. 目标与技术栈
构建 FlowStudio Monorepo 脚手架、React Flow 基础画布、9 种流程图节点类型、正交连线、属性面板、悬浮工具栏、暗黑/明亮主题及 localStorage 单机持久化，为 M2 实时协同打下坚实的前端底座。
- **技术栈**：pnpm 9 monorepo, TypeScript 5.6, Vite 6, React 19, @xyflow/react 12, Tailwind CSS v4, shadcn/ui, Zustand, Lucide-react, Zod。

### 2. 阶段任务拆分与实施进展
- **Task 1: Monorepo Scaffold + Dev Tooling**
  - 初始化 `pnpm-workspace.yaml`，划分 `packages/web`、`packages/server`、`packages/shared` 三大包；
  - 配置全局 TypeScript、ESLint 与 Vitest 基础环境，确保全仓类型严格模式。
- **Task 2: Design Tokens + Theme System**
  - 基于 CSS Custom Properties 建立现代设计令牌系统，杜绝裸硬编码色值；
  - 实现 Light / Dark 双主题一键平滑无损切换。
- **Task 3: Shared Types + Node Registry**
  - 在 `packages/shared` 建立节点契约规范与 `NODE_REGISTRY` 注册表；
  - 规范 9 种基础图元元数据（开始/结束、处理、判定、圆形、菱形、数据库、文档、子流程、便签）。
- **Task 4: Zustand Store + localStorage Persistence**
  - 构建前端状态机，统一管理画布节点、连线与交互态；
  - 接入本地离线缓存持久化。
- **Task 5: React Flow Canvas + 模块化图元外壳 (BaseNodeWrapper) + 组合框选 + 正交连线**
  - 封装通用的 `BaseNodeWrapper` 模块化图元容器，提供对齐、锚点、尺寸拖拽缩放能力；
  - 实现节点框选、Group / Ungroup 逻辑分组与防穿透控制；
  - 落地基础直角正交连线计算。
- **Task 6: Shape Palette (左侧资产面板) + 拖拽添加**
  - 实现侧边栏图元抽屉，支持将节点拖拽至画布指定坐标并精准实例化。
- **Task 7: Property Panel (右侧属性面板)**
  - 支持选中节点或连线时修改文本、字体、颜色、边框、粗细等通用样式。
- **Task 8: Floating Toolbar (悬浮快捷工具栏)**
  - 提供画布上方的快捷操作条（缩放比例、撤销重做、成组、适应画布）。
- **Task 9: Top Bar + 全局布局组装**
  - 组装 TopBar 导航条、标题快速重命名、图列表入口与主题切换开关。
- **Task 10: Polish + M1 质量门禁验收**
  - 综合走查交互细节与高频操作边界，单机流程图编辑器构建零报错交付。

## 五、M4 里程碑：AI 协作者 (MCP) 与无损快照系统

### 1. 目标与技术栈
实现成熟商业级的 AI 人机共治体系（Fastify MCP Streamable HTTP 与 stdio 桥接、服务端内部 Yjs AI 协作者、7 大标准 MCP 协同工具、AI 批次可撤回与防冲突保护）、版本快照管理与无损差异回滚、前端全格式无损导出及局域网一键启动脚本。
- **技术栈**：JSON-RPC 2.0 / Streamable HTTP, `@modelcontextprotocol/sdk`, SQLite 快照差量解算。

### 2. 阶段任务拆分与执行闭环 (SDD 进度追踪)
