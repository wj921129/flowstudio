# FlowStudio 已实现功能归档

## 功能列表简述
FlowStudio 已完成从底层协作内核到前端交互工作台的全功能交付，涵盖 7 大核心模块共 25 项细分功能：
1. **画布与节点**：9种基础流程节点、自由分组框与混合成组、极窄像素自动吸附与对齐辅助线、连线断键智能串接推挤、节点锚定锁机制。
2. **泳道与排版**：多向Pool/Lane泳道系统、elkjs泳道感知拓扑自动排版、智能正交直角折点连线。
3. **多人协同**：分布式CRDT实时协同引擎、实时感知与多人光标、客户端隔离协同撤销重做、匿名访客身份与本地持久化。
4. **AI人机共治**：7大标准MCP画布操作工具、轻量跨平台stdio MCP桥接脚本、在线优先写入引擎与字段级AI撤回账本、AI批次Visual Diff逐项审阅台。
5. **快照与数据**：无损差量快照引擎与时间线抽屉、Mermaid双向同频抽屉、因果链路聚光灯带看与跟随、高保真全格式图表导出。
6. **工作台与运维**：现代风格工作台与双主题切换、停靠式侧边栏工作台、图表资产仪表盘、局域网一键启动脚本。
7. **确定性范式渲染**：vertical-flow 分支网格、便签左置、回归走线、主干留白与人机语义对齐。
